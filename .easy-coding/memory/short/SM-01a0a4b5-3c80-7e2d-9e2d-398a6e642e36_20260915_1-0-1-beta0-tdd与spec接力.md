## 技术记忆候选

- TDD 初始化凭据中的文件摘要记录初始化历史。日常 readiness 校验必要本地入口和参数契约，普通版本、依赖、插件、CI 或格式变化不会触发重新初始化；当前测试和覆盖率结果继续决定验收。
- 构建文件、覆盖率工具及初始化凭据的实际内容纳入任务实施和验证契约指纹，构建变化不能沿用旧覆盖率或旧验收证据。无凭据使用 needs_init，已有凭据或必要入口损坏使用 needs_repair。
- 升级保留项目和 session 显式 TDD 开关、阈值、继承关系及任务冻结基线；升级时的 session 清理保护带有显式 TDD 配置的记录。readiness 失败只报告修复需求，不自动关闭 TDD。
- 任务持久化 Canonical 来源、选中任务、设计身份和待同步状态。新 Agent 重新加载原稿的选中消费范围，阶段门禁检查当前 session 的消费记录；确认需求变更先登记，再修改原稿并同步设计。
- 上下文门禁位于产生验收或共享进度副作用的公共状态 API，不能仅依赖 CLI 命令白名单。记录阶段确认和验收结果之前必须完成校验。
- 设计同步使 hard 依赖证明失效时，允许保存新设计绑定，并通过上下文恢复、补交证明、再次修订或取消解除待补充状态；任务创建、普通实施和验收继续执行严格依赖门禁。
- 恢复写回分别传递原事件作者和当前执行者。沿用原动作及幂等键保证源事件只写一次，当前负责人保持为接手者。取消恢复只接受已持久化、选中来源任务的指定取消链动作。
- 中断恢复回归覆盖 writer 执行前与成功后丢失本地确认两种边界，并同时核对源事件数量、事件作者、本地 pending_action、当前负责人及 session 指针。
