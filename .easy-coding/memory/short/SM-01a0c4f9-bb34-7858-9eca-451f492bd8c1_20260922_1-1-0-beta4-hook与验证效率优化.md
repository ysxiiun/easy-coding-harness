## 技术记忆候选

- Hook 在禁用或不处于项目范围时尽早退出；正常状态路径只加载 operation/store/status，避免导入状态机和 Spec 引擎。本地 9 次进程测量的模块加载中位数从 89.42 ms 降到 11.08 ms，测量不含完整进程启动成本。
- 同次操作的 JSON、配置和执行日志读取可复用；写入、重命名和回收必须使对应缓存失效。约 8 MB 执行日志的同次 Hook 读取从 2 次降到 1 次，session/task/config 等读取也降到各 1 次。
- 只有识别明确的单进程、文件级测试选择器，且 Unit 声明完整 `input_files` 时，才缩小测试输入；生产源码、显式 helper、fixture 和构建配置仍属于输入。复合命令、未知选项或不完整声明沿用模块范围；Maven/Gradle/tsc 保留编译输入。
- 验收只在 Git 对象与模式未变、工作区无相关变化且索引状态可信时复用已有内容。assume-unchanged 和 skip-worktree 必须读取实际字节；新增、删除、重命名、模式和符号链接仍受全仓检测。自动验收复用本次新鲜漂移结果，将同次漂移检查从 2 次降到 1 次。
- Spec 写回复用前置检查结果并保留一次写后检查；解析结果只在同次操作、相同文本及相同校验标志下复用。正常写回完整校验由 6 次降到 4 次，CAS、幂等与协议约束保持不变。
- 阶段指令优先使用已有 batch API，返回项包含 task/stage/next_action，减少准备和登记的往返次数；跨平台安装与清理继续通过现有平铺 Python 文件枚举机制覆盖新增模块。
- 测试应隔离用户级行为配置；记录完整运行和定向复验各自的真实退出码。用工作次数断言验证优化，同时保留实际行为回归，避免只以行数或不稳定的墙钟阈值判断收益。
